## Risks & open questions
- **No database in `scripts/check`.** `PgFeatureBoard` SQL is untested by the gate.
  Recommendation: VERIFY runs the built server against a **throwaway Neon branch** (Neon MCP:
  create branch → apply `roadmap-schema.sql` → seed → run the board flows → delete the branch). It
  never touches production data. Creating and deleting the branch is asked for at VERIFY.
- **Production schema.** The tables must exist in production before this deploys, or `/roadmap`
  shows "board unavailable" (R7). That is degraded, not broken. Recommendation: at ship, ask, then
  apply the idempotent `roadmap-schema.sql` to production **before** merging.
- **`ADMIN_EMAILS` in production.** Without it nobody can moderate (AC-10). It is set in Coolify by
  the owner, and the ship gate reminds them.
- **Hand-merge of 5 shared files.** Recommendation: take the owner's roadmap hunks with
  `git merge-file` against `b0be0ff`, as in the 0002 sync, and review that diff closely.
